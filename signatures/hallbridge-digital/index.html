  1. Click just to the left of the logo, hold, and drag to the end of the HALLBRIDGE logo button so the whole signature is highlighted. Copy it (Cmd+C).
  2. Gmail: gear at the top right, See all settings, General tab, Signature, Create new. Name it Hallbridge Digital, paste (Cmd+V), and Save Changes at the bottom.
  3. Outlook: Settings, Signatures, New signature. Name it Hallbridge Digital, paste, and Save.
  4. To use it, pick Hallbridge Digital from the signature menu in a new email.
